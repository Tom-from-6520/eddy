# Security

If you find a security issue in eddy, please report it privately through [GitHub's private vulnerability reporting](https://github.com/Tom-from-6520/eddy/security/advisories/new) instead of opening a public issue.

Please include what you found, how to reproduce it, and which eddy version you used. You'll get a response as soon as possible.

Vulnerabilities in the upstream Code - OSS code that also affect Visual Studio Code should be reported to Microsoft as described in the [VS Code security policy](https://github.com/microsoft/vscode/blob/main/SECURITY.md).
